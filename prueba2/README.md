# NextDigital — prueba 2

Next.js (App Router, static export) + Tailwind v4 + shadcn/ui + framer-motion, tema oscuro.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # genera out/ (sitio estático)
```

Componentes de terceros (VengeanceUI) en `components/ui/`: `cylinder-carousel`, `notch-navbar`, `glass-dock`,
`agent-bento-grid`. Secciones en `components/site/`; datos en `lib/site.ts`.
