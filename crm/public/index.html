Conectar WhatsApp

Dos formas de traer tus chats. Ninguna envía mensajes por ti.

Opción 1 · Código QR

  1. En otra terminal, dentro de la carpeta crm, corre npm run whatsapp.
  2. En tu teléfono: WhatsApp Business → Dispositivos vinculados → Vincular dispositivo.
  3. Escanea el código. El historial tarda unos minutos en llegar.

Esperando código… (corre npm run whatsapp)

El lector solo lee. Puedes desvincularlo cuando quieras desde tu teléfono.

Opción 2 · Chats exportados

  1. En cada chat: ⋮ → Más → Exportar chat → Sin archivos.
  2. Sube aquí los archivos .txt.
